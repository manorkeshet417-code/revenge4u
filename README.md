# REVENGE 4 YOU!

A fan-made revenge planner app. Plan revenges, track the active ones, favorite them and keep an archive.

**Open it:** https://manorkeshet417-code.github.io/revenge4u/

- Installable as an app (phone home screen / desktop), works offline
- English, עברית, العربية, Русский
- Original (explosive) and Office designs
- Everything is saved only on your own device

Made by Man Studio.
